1. Objective

The hiring brief evaluates an agent-assisted QA workflow, not hand-written tests claimed as AI work.

  • Application: InvenTree — Parts module only
  • Phase 1: ingest docs, write comprehensive UI cases
  • Phase 2: ingest API schema, write API cases + runnable scripts
  • Phase 3: UI automation for CRUD + one cross-functional flow

Stack TypeScript + Playwright   Target demo.inventree.org

2. Sources ingested by the agent

  • https://docs.inventree.org/en/stable/part/ and sub-pages (views, create, templates, revisions)
  • https://docs.inventree.org/en/stable/concepts/parameters/
  • https://docs.inventree.org/en/stable/api/schema/part/
  • Live OpenAPI /api/schema/ on the demo (API 540) — used to correct stale paths

Prompts used for this ingest live in agent-artefacts/prompts/.

4. Generated automation scripts

POST /api/part/          → 201 + Zod partSchema
GET  /api/part/?search=  → created pk present
PATCH active=false       → then DELETE succeeds
POST /api/parameter/     → model_type=part.part, model_id
POST /api/stock/         → in_stock increases

UI page objects use PUI names discovered on the live app:

  • login-username / login-password / Log In
  • /web/part/category/{id}/details/parts for create
  • action-menu-add-parameters-create-parameter + text-field-data

5. What the architect changed after generation

  • Parameter APIs moved to /api/parameter/ (not /api/part/parameter/)
  • Active parts cannot be deleted until deactivated
  • Stock create returns an array; IPN filter may return a bare array
  • Login wait must target the Parts tab, not a navigation landmark

See agent-artefacts/agent-review-notes.md.

6. How to run and watch the videos

cd automation
copy .env.example .env
npm install
npx playwright install chromium
npx playwright test --project=api
npx playwright test --project=chromium
